# PyrateRadio

**Analog SIGINT & Resilient Communications Reference**

PyrateRadio is a wiki-style reference for peer-to-peer (P2P), free-to-air (FTA) analog radio systems. It focuses on practical knowledge for monitoring, local coordination, and long-range skip when digital infrastructure fails.

This is educational material for friends, family, and anyone interested in analog backups. It is not operational guidance for illegal activity.

## Philosophy

Simple radios that talk radio-to-radio. No keys, no servers, no subscriptions. When the digital world goes dark, analog still works locally and, when the ionosphere cooperates, much farther.
